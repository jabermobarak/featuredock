# FeatureDock

Пайплайн данных для ML. Он хранит время события и время получения данных. Позднее событие не меняет прошлый прогноз.

Данные датчиков созданы программой. Модель оценивает риск условного сигнала в следующий час. Это не модель поломки реального оборудования.

## Запуск

Нужен Python 3.11 или 3.12. Для обычного демо Java и GPU не нужны.

```bash
python -m venv .venv
# Windows PowerShell:
# .venv\Scripts\Activate.ps1
# Linux / macOS:
source .venv/bin/activate
python -m pip install -e '.[dev]'
python -m featuredock.cli demo
python -m featuredock.cli serve
```

Откройте http://127.0.0.1:8020.

Выберите датчик и время. Таблица покажет, какие данные были известны тогда. Справа можно проверить три случая: повтор события, ошибка в данных и позднее событие.

Повтор не создаёт новую запись. Ошибка попадает в карантин. Позднее событие хранится в базе, но не попадает в прошлый прогноз.

## PySpark

Для проверки пакетного расчёта нужны Java 17 и PySpark:

```bash
python -m pip install -e '.[dev,spark]'
python -m featuredock.cli demo --retrain --spark
```

Результат сравнивается с SQL для тех же моментов времени. В отчёте есть число строк и максимальная разница.
